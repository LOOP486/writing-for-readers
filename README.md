# writing-for-readers

一个 Claude Code / Claude skill，用来治 AI 写文档的通病：先分清文档给谁看，再动笔。

## 它解决什么

AI 写出来的文档常常"一股 AI 味"——外人一眼认出、不愿意读。这个 skill 用一条主线和五条硬规则约束写作：

- **先定读者**：这份东西给谁看、他看完要能干什么。默认按"外人"处理。
- **分清内外**：给自己/协作 AI 看的（内）可留状态标注、待办；给别人看的（外）严格清除内部口吻。
- **五条硬规则**：不泄露内部口吻、凝练、不反复、不造词故作高深、**不把方法论框架（机制轴/闭环/自检/T1T2T3/验收尺子）当正文摆出来**。

最后一条是最容易忽略、也最致命的：设计时用的检查框架是你的脚手架，不是给读者的内容。把框架用掉、别写出来。

## 安装

放到 Claude Code 的 skills 目录即可：

```
~/.claude/skills/writing-for-readers/SKILL.md
```

之后写文档、润色、或说"这段像 AI 写的"时会自动触发。

## 文件

- `SKILL.md` — skill 正文（含主线、五条规则、写后自检清单、反例改法表）
